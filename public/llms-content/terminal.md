# Terminal

## TL;DR

Install Windows Terminal, the tool you'll use throughout this guide to run WSL 2 commands and to open dedicated tabs for your AlmaLinux 10 distro. Once the distro is installed, it gets its own dedicated tab profile, so every command in the guide (Windows and Linux alike) can be run from the same app.
