# WSL 2 development environment

This folder contains the Ansible playbook used to provision a local development environment (Apache, PHP-FPM, MariaDB, phpMyAdmin, Composer, and Node.js).
It runs directly on Linux or via WSL 2 on Windows, and is designed for development in any PHP framework or project.

Full, up-to-date installation instructions: <https://docs.dotkernel.org/development/v2/setup/installation/>
